From representations to geometry

What foundation models contribute—and what gets fine-tuned

“Foundation model” describes broad pretraining and reuse. It does not specify the output units, the training objective, or the reliability of a particular checkpoint.

Reading an architecture as a pipeline

DPT reassembles transformer features into spatial feature maps and combines them through a dense prediction decoder [2]. This bridges a representation that captures broad image context and a task that needs an answer at each pixel.

For the V2 implementation, an RGB image is resized and normalized, passed through a pretrained encoder, decoded into relative inverse depth, and resized back to the original image grid. Upsampling makes an output align with the image; it does not create independent evidence for every fine edge. The demonstration shows inputs, outputs, and preprocessing shapes, rather than internal attention maps or a causal explanation of individual predictions.

What the encoder and decoder actually do

A transformer first represents image patches as feature vectors. In a self-attention layer, learned projections form queries Q, keys K, and values V. The operation softmax(QKᵀ/√d)V mixes information according to learned feature relationships. This lets a patch representing a chair depend on distant floor or room context. The attention weights are not depth measurements, and their presence alone does not identify which cue caused a prediction.

A dense decoder must turn features back into a spatial field. It combines representations at different effective resolutions: broad context supports room layout while finer features support contours. Resizing and fusion connect these scales. A final prediction head maps each location to the task output. The output is then interpolated to the original image size so annotated pixels can be addressed consistently.

The pretrained representation supplies visual regularities learned before this particular depth task. Depth supervision and the decoder determine how those regularities are translated into geometry. An image-generation model follows a different route: iterative denoising can be conditioned to produce a depth representation. “Fine-tuned foundation model” therefore needs a concrete answer about which pretrained components are retained, which parameters change, and which target is optimized.

Two routes from foundation models

Representation transfer

Depth Anything V2

V2 uses a DINOv2-based teacher trained with precise synthetic depth, then real-image pseudo-labels to train student models [3]. Our Small checkpoint predicts relative inverse depth. The project also provides separately trained metric variants; the relative checkpoint does not inherit their units.

Generative transfer

Marigold

Marigold adapts Stable Diffusion for depth estimation, retaining its latent image representation and fine-tuning the denoising network to generate depth conditioned on an image [4]. Its original formulation predicts affine-invariant depth. This is a direct example of repurposing a generative foundation model; we reviewed it but did not run it locally.

When the task requires meters

Metric3Dv2 uses a canonical camera-space formulation to address differing camera intrinsics, with joint depth and surface-normal reasoning [5]. Camera conventions matter: metric evaluation must account for focal information and the method’s transformations. Depth Pro targets sharp metric depth through a multiscale transformer system and includes focal-length estimation [6]. These are literature alternatives, not measured competitors in our local table.

For a reconstruction pipeline, choosing a metric model is only the beginning. Record whether focal length is known or estimated, how crops alter intrinsics, and whether predictions generalize to the intended camera. A convincing indoor result does not establish calibrated performance for a wide-angle phone or an unfamiliar outdoor scene.

Recent adaptation and broader geometry

DepthAnything-AC fine-tunes a pretrained depth model using unlabeled images, perturbation consistency, and a patch-level spatial-distance constraint [7]. The training asks a student to preserve geometric predictions under appearance changes while retaining information from a frozen model. We run the authors’ adapted Small checkpoint; we do not perform our own fine-tuning.

Depth Anything 3 extends the setting to any number of views, with a transformer architecture and joint depth/ray representation [8]. Our DA3-Small experiment supplies one image. It does not evaluate multi-view reconstruction, camera recovery, or the separate large monocular and metric variants. A family name is therefore too broad to identify an experimental condition.

DepthART, a 2026 paper, explores distillation into a tiny model and camera-specific adaptation [9]. This makes compression and adaptation part of the updated research scope. We did not run its checkpoint or measure a phone: the tutorial cannot convert its published efficiency claims into observed mobile results.

A useful training abstraction

For a relative predictor, a naive squared error against meter-valued targets can penalize an otherwise consistent layout simply because scale is arbitrary. A generic affine-invariant objective compares a fitted prediction with a compatible target: minₐ,ᵦ mean((a q + b − q*)²). A positive scale preserves ordering. An edge term can separately penalize differences in spatial gradients, placing pressure on boundaries that an average pixel loss can overlook.

A generic consistency objective instead compares predictions on an image and an appearance-transformed copy after putting them in compatible coordinates and scale. A frozen teacher can provide an anchor while a trainable student processes the harder input. These equations explain the design questions; they are not a transcription of every cited model’s exact loss or an objective we trained here. Check the primary paper for masking, normalization, weights, and additional constraints before implementing its method.

What an adaptation experiment would need

A clean fine-tuning study would separate training, validation, and test images before choosing transformations; preserve an untouched pretrained baseline; and track both target-domain gains and general-domain regressions. Freeze or update the encoder deliberately, report the choice, and choose stopping criteria on validation data. Keeping an independent clean test set is how one detects catastrophic forgetting rather than simply celebrating improved training examples.

For unlabeled adaptation, teacher predictions are targets with inherited mistakes. Appearance consistency can regularize a student, but stable wrong geometry is still wrong. Strong augmentations can also destroy the visible evidence needed to identify a surface. Our small study tests checkpoint behavior; it does not identify which loss, dataset, or layer caused a difference.
