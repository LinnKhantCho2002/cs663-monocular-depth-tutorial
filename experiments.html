After the guided examples

Try another scene in the full explorer. Magnify a glass rim or a chair leg and compare its edge with the photograph. These free inspections do not have dense reference labels, so describe what you see without assigning an accuracy score.

Look between the marked points

Press Reveal depth map and adjust the overlay. Select Move A or Move B, then click to place a point. Shift-click moves B; arrow keys move the selected point when the image has focus. Reset restores the annotation.

Larger inverse-depth values mean closer within the selected prediction. Once you move a point, it becomes a free probe with no reference label. The original annotation applies only to its marked coordinates.

Try itUngraded · choose to reveal

You move A away from its annotated location. Can the original label still tell you whether the new pair is correct?

The label applies to the original coordinates. A moved point is a free probe. Its predicted value is useful to inspect, but you need a new reference label to score the new pair.

The profile plots inverse depth along the image line from A to B. Place the probes on opposite sides of a chair leg and look for a jump. The horizontal axis is image position, not distance through the scene.

Free probes and profiles sample a 16-bit display grid with a maximum 512-pixel long edge. Their values are approximate. Annotated-point scores use exact values saved from the full-resolution predictions. Magnification enlarges the view around A without adding model detail.

Compare with the sensor reference

Choose a NYU scene and model, then switch the right image between the relative prediction, filled reference, oracle-aligned prediction, error, and scoring mask.

The reference and aligned maps share a 0.1–10 meter color scale. The error range is 0–0.5; excluded pixels are dark blue-gray. White mask pixels contribute to the scores.

Start with the kitchen. Compare a cabinet in the aligned prediction and reference, then use the error map to find the remaining mismatch. The fit below the images shows how the reference supplied the scale and shift.

Make one specific observation

Name the scene, model, condition, and reference. For example: “On the original mirror image, V2 reverses pair 2's annotated ordering. DA3 gets that pair right.” Then check whether the surrounding map supports a broader claim.

A pair score covers two points. Try a thin edge or a different scene before deciding how well the model handles the whole image. For your own photos, use the Python walkthrough and keep the results separate from this fixed comparison.
