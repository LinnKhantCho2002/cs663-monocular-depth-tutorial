Start with the mirror example below. Keep the input fixed while switching models, then keep the model fixed while changing the input. This makes the differences easier to follow.

Three examples to explore
  1. Car mirror: choose the original input and pair 2. V2 and AC disagree with the source annotation; DA3 agrees. Reveal the maps and compare the surrounding region.
  2. Tripod room or foggy traffic: compare the original input with strong dimming. Look for changes in the marked pair and in the overall map.
  3. Glass rims and chair legs: use the wine-glass or classroom scene. Increase the overlay and magnify a thin edge. Compare its outline with the prediction.

Using the probes and profile

Click Reveal depth map to add the prediction, and adjust the overlay to compare it with the photograph. Select Move A or Move B, then click a new location. You can also Shift-click to move B, or focus the image and use the arrow keys. Reset returns both points to the selected annotation.

The values are relative inverse depth, so a larger value means closer within that prediction. Moving the probes gives you a way to inspect an edge or compare foreground and background. Arbitrary probe positions have no reference label; the source annotation applies to its original marked points.

The profile plots inverse depth along the image line from A to B. Try placing the points on opposite sides of a chair leg or a glass rim. A jump in the curve shows a change in the predicted field. The horizontal axis follows image position, so it is not a physical cross-section through the scene.

Display resolution

The browser loads saved local predictions. For faster loading, free probes and profiles use a grid with a maximum 512-pixel long edge, quantized to 16 bits using the original array’s minimum and maximum. Those samples are approximate. The annotated-pair panel uses separate exact values from the full-resolution output.

Magnification enlarges the displayed region around A. It helps you see the overlay and position the probes, but adds no new model detail. The caption below the image links to the source dataset and names the archive photograph.

2. Compare with sensor depth

The second explorer uses six NYU indoor scenes. Choose a model and switch the right-hand image between relative inverse depth, filled sensor reference, oracle-aligned prediction, relative error, and the scoring mask.

For the reference and aligned maps, the color range is shared: 0.1 to 10 meters. The error display uses a fixed range from 0 to 0.5, with excluded pixels shown in dark blue-gray. White pixels in the scoring mask are included in the metrics.

Try the kitchen scene first. Inspect a wall or cabinet in the relative map, then select the aligned map and reference. The scale and shift shown below explain how the relative output was fitted to that reference. Use the error map to find where the fit still leaves a mismatch.

A useful observation to write down

Record the scene, model, and condition. Describe what changed at a marked pair or boundary, then say which reference supports the observation. For example: “V2 reverses the source ordering for mirror pair 2 on the original image. DA3 orders that pair correctly.”

A correct pair checks two points. Inspecting the rest of the map can reveal details that the pair score does not cover. Comparing several scene types is useful for the same reason: a mirror and an ordinary room challenge a model in different ways.

The local Python implementation supports new photographs and fresh transformations. Keep those results as additional experiments so the original comparison remains reproducible.
