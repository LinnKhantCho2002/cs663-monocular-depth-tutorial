What is happening in this viewer?

The selected input was processed by the named checkpoint on the laptop. The browser loads that saved prediction, overlays a color rendering, and samples a reduced grid for free probes and profiles. It does not retrain, run inference, or infer confidence from a smooth-looking map. A profile plots predicted inverse depth along the line between two image points, not a physical cross-section through the room.

For fast loading, the public display grid is bounded to a 512-pixel long edge and quantized to 16 bits using each array’s full-resolution minimum and maximum. Free probes and the line profile are approximate display samples. Annotated pairs use separate exact full-resolution values. Magnification enlarges the displayed region and does not recover additional neural detail.

The selected source caption identifies the dataset, archive image, and reference link. Photograph rights remain with their respective owners; dataset availability and a model’s software license do not establish a blanket license for every photograph. Existing watermarks are preserved. Do not reuse these images under a model-code license.

2. Sensor-reference explorer

Choose any of six NYU scenes and any of the three native comparison checkpoints. Compare RGB with relative inverse depth, the filled sensor reference, the oracle-aligned prediction, a relative-error map, or the exact scoring mask. Sensor reference and aligned maps use a common 0.1–10 meter display range. Invalid error pixels are dark; the mask identifies the pixels actually scored.

The filled map shows the available reference throughout the scene; the mask deliberately excludes raw sensor holes and the outer crop. Error colors use a fixed relative-error range from 0 to 0.5 so switching models retains the display convention. The panel reports the case-specific scale, shift, pixel count, and clipping fraction.

Explain one observation

Use this form: “On [scene], under [condition], [checkpoint] predicted [ordering or pattern]. The available reference verifies [specific quantity]. This does not establish [broader claim].” A well-scoped failure is more informative than an unexplained screenshot of a colorful map.

To test a new photograph or a new transformation, use the local Python implementation. New inputs are outside this frozen study and should be recorded as additional experiments rather than silently replacing the original sample.
