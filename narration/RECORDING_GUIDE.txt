Page narration — Linn Khant Cho
==============================
Use your own voice. Read and revise the script so you can explain every sentence.
Each short clip introduces its page; the written lessons provide the details.

The easiest route
1. Open the page on the public HTTPS website or the local HTTP preview.
2. Expand "Page narration: listen, read, or record".
3. Expand "Record your own narration". Press Record and allow microphone access.
4. Read the script above slowly. You can pause naturally. Press Stop when finished.
5. Listen with the preview player. If needed, choose Record again.
6. Press Download clip BEFORE changing pages. Check your Downloads folder.
7. Repeat for the next page.

Recording is local. Nothing is uploaded and the public page voice remains pending.
The clip is temporary until downloaded. Changing pages can lose an unsaved take.
Most clips take about 45–70 seconds. Seven clips usually take around 10–15 minutes including retakes.

Files are named automatically:
index, geometry, methods, evaluation, experiments, conclusions, bibliography.
The browser chooses .webm, .m4a or .ogg depending on supported recording formats.
Keep the filename and extension. Do not rename an encoded .webm file to .m4a.

To add the real clips to this project
Place the seven downloaded files in site/narration/.
From the project folder run:
    .venv/bin/python scripts/build_site.py --content-only
The builder supports .m4a, .webm, .ogg, .mp3, .wav and .mp4.
Use one final clip per page and remove superseded versions. Test every audio player locally before publishing. Verify playback again on the public website after the Pages build completes.

If browser recording is unavailable
Use Voice Memos on the Mac, record each script, and export each clip as the matching page-name.m4a. Keep a quiet room and a consistent microphone distance.
Headphones help when reviewing. Aim for clear explanations, not a perfect announcer voice.

Pronunciation
RGB: R G B; DPT: D P T; DINO: dee-no; NYU: N Y U;
DA3: Depth Anything Three; AC: A C; AbsRel: absolute relative error.

Content checks
Relative inverse depth uses arbitrary units; higher means closer.
The browser displays saved inference; it does not run a neural model.
NYU scores use oracle alignment on the scored reference pixels.
The AC authors fine-tuned their checkpoint; this project did not train it.
The small local comparison is not a full benchmark or a phone deployment.

The downloaded clips are separate from the full spoken presentation video.
The webpage-voice requirement is complete only when your recordings are added, published and tested.
