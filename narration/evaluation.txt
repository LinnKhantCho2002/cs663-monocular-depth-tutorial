The point-pair test asks which marked point is closer. V2 and AC each get thirty-four of thirty-five clean pairs right. AC retains more correct pairs under strong dimming and blur. The NYU test compares dense predictions with sensor depth after fitting scale and shift. The fit uses the same reference pixels as the score, so a low error shows aligned shape agreement, not raw accuracy in meters. This is a small fixed sample, and transformed versions are not independent scenes.
