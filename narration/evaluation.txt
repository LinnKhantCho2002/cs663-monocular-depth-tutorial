The comparison uses fifteen DA-2K photographs with thirty-five annotated near and far pairs. Each model processes the original images, two dimming conditions, and a blurred condition. The same coordinates are scored each time. V2 and AC both get thirty-four clean pairs right. Under strong dimming, AC keeps thirty-four and V2 keeps thirty-two. Six NYU indoor scenes provide a second evaluation using sensor depth. Because the predictions are relative, the code fits a scale and shift before computing error. The fit uses the same reference pixels that are scored, so the result measures shape agreement after oracle alignment. It does not demonstrate raw meter accuracy. The evaluation page gives the mask, transformations, metrics, timing setup, and limits of the small sample. The saved-case download lets you recompute a kitchen example. An optional walkthrough also provides the source and commands for fresh inference and the fixed native comparison.
