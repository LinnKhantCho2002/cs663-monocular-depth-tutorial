Testing monocular depth models
==============================
This tutorial is about how recent depth models respond to dimming and blur. Monocular depth estimation means predicting depth from one photograph. I compared V2 Small, AC Small, and DA3 Small on fifteen photos, using the same original and changed inputs for each model. AC is adapted from V2, so I wanted to see whether it kept more near and far answers correct. The guides cover the model papers, the experiment, and the results. The main examples are a mirror, a traffic scene, and a kitchen. I used the published models; I didn't train them myself.


Which point is closer?
======================
A mirror makes depth harder to read because a nearby surface reflects another scene. A and B mark two locations in the photo. Take a moment to choose which is closer before opening the model maps. The models disagree on this pair. Their inverse-depth values explain each answer: a larger value means closer. The source label tells us which answer matches these two points. The dataset gives each model the same question, so we can check their answers directly.


Depth, scale, and the camera
============================
A single photo leaves the physical scale uncertain. If we double the size of a room and move everything twice as far from the camera, its image can stay the same. A model can still use overlap, perspective, and familiar objects to estimate near and far. The models in this experiment give relative values, rather than distances in meters. Their color ranges are separate too, so yellow in one map isn't the same distance as yellow in another. This matters when we compare their predictions with each other or with a sensor.


How the models learn depth
==========================
The main difference I'm studying is how the models learn depth. V2 uses pretrained image features and depth labels generated by a teacher. AC adapts V2 to keep predictions consistent when appearance changes. DA3 uses a different approach to geometry; I tested its Small model with one image. In the traffic example, dimming changes V2's answer even though the objects haven't moved. AC and DA3 keep all three pairs correct on that photo. Consistency alone isn't enough, though: a model could keep the same wrong answer. The point labels let us check both stability and correctness.


Putting the predictions to a test
=================================
I used two types of reference. DA-2K gives near and far labels for pairs of points. NYU provides indoor sensor depth, which lets us compare surfaces across an image. The models' relative outputs have to be fitted to that reference before I can score them in meters. For the kitchen, V2's aligned error is about zero point zero two six. That is a low average, but the error map still shows a mismatch near the counter edge. The fitted scale and shift come from the sensor reference.


Test what changes
=================
Here you can compare the same photo under dimming and blur. The original stays on the left, and the selected input is on the right. The model results are saved from the experiment. On the traffic photo, V2 gets all three pairs right on the original, but only one right under severe dimming. AC keeps all three right. Changing the model lets you compare that difference on the same input. The optional point inspector measures other locations in the map. The kitchen comparison goes further by showing the sensor reference and an error map.


What the comparison showed
==========================
On these selected photos, AC keeps more pairs correct than V2 under strong dimming and blur. They both get thirty-four of thirty-five pairs right on the originals. With strong dimming, AC stays at thirty-four and V2 falls to thirty-two. DA3 gets the mirror pair right, but its overall count falls more under the changed inputs. These results describe the released models on this small sample. The next test would use more independent scenes and actual low-light photographs, rather than digital dimming alone.
