This tutorial is about estimating depth from one photo. When we look at a room, we can usually tell which objects are in front and which are farther away. But the photo doesn't give us a distance measurement. How does a model work that out, and when does it get confused? I compared three released models using photos, dimming, and blur, plus a few indoor scenes with sensor depth. We'll start with a mirror photo, then work through the geometry, models, and results. Try the questions as you go. You don't need to install anything to use the examples.

Can a model tell how far away something is from just one photo?

A photo has no depth measurements. We can still recognize that a chair is in front of a wall, or that a road stretches into the distance. Monocular depth estimation asks a model to make similar predictions from a single image.

In this tutorial, we'll look at how these models work and test where their predictions hold up. I compared Depth Anything V2 Small, DepthAnything-AC Small, and Depth Anything 3 Small using original photos, dimming, and blur. We'll also compare predictions with indoor sensor-depth examples.

How to use the tutorial

Follow the lessons in order. Try the short questions before revealing the explanations, then use the explorer to compare models and change the input. The questions are ungraded, and you can try them again.

By the end, you should be able to read a depth map, explain why relative depth is different from meters, and use an example to discuss a model's strengths and mistakes.

Basic familiarity with images and neural networks will help. The paper links, expanded method notes, and Python walkthrough are there if you want to go further. You can use all the saved examples without running a model yourself.
