This project studies how recent monocular depth models behave on difficult images.

Monocular depth estimation predicts depth from a single photograph. I compared Depth Anything V2 Small, DepthAnything-AC Small, and Depth Anything 3 Small on the same 15 photos, then repeated the comparison with dimming and blur.

Research question

When dimming and blur change a photo, which models keep the near/far ordering correct? How does the adapted AC checkpoint compare with V2?

The paper review examines foundation models and how researchers adapt them for depth prediction. The experiment checks the released checkpoints against annotated point pairs and six indoor sensor-depth examples.

We'll use a mirror to examine model disagreement, traffic to test appearance changes, and a kitchen to explain reference-based evaluation. The geometry guide provides the background needed to read those results.

How to use the tutorial

Follow the guides in order. Try the short questions before revealing the explanations, then use the explorer to compare models and change the input. The questions are ungraded, and you can try them again.

By the end, you should be able to explain what adaptation tries to improve, compare predictions with a reference, and describe what this experiment does and does not show.

Basic familiarity with images and neural networks will help. The paper links, expanded method notes, and Python walkthrough are there if you want to go further. You can use all the saved examples without running a model yourself.
