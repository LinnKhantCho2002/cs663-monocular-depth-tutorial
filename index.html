Blur the background of a photo. Keep the person sharp. What happens if the depth model loses a chair leg or a glass rim?

A photo editor needs to separate foreground from background. A wrong depth prediction can blur the wrong surface or leave a visible outline. The same near/far judgment matters in scene reconstruction, although recovering physical distances asks more of the model.

Monocular depth estimation predicts depth from one RGB image. This tutorial asks: how much can we trust that prediction?

We'll use three examples: a mirror where the models disagree, a traffic scene changed by dimming, and a kitchen with sensor depth to check against. Along the way, we'll look at recent foundation models and how researchers adapt them for depth.

How to use the tutorial

Follow the lessons in order. Try the short questions before revealing the explanations, then use the explorer to compare models and change the input. The questions are ungraded, and you can try them again.

By the end, you should be able to read a relative depth map, explain what adaptation tries to improve, and use a measured example to discuss where a model succeeds or fails.

Basic familiarity with images and neural networks will help. The paper links, expanded method notes, and Python walkthrough are there if you want to go further. You can use all the saved examples without running a model yourself.
