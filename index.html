This tutorial explains monocular depth estimation: how a model predicts depth from a single photograph.

I reviewed recent research on foundation models for depth estimation and how researchers adapt them for this task. I also compared three released models: Depth Anything V2 Small, DepthAnything-AC Small, and Depth Anything 3 Small.

We'll go through what a depth map means, how the models learn, and how to check their predictions. The examples include a mirror where the models disagree, a traffic scene before and after dimming, and a kitchen with sensor depth as a reference.

How to use the tutorial

Follow the lessons in order. Try the short questions before revealing the explanations, then use the explorer to compare models and change the input. The questions are ungraded, and you can try them again.

By the end, you should be able to read a relative depth map, explain what adaptation tries to improve, and use a measured example to discuss where a model succeeds or fails.

Basic familiarity with images and neural networks will help. The paper links, expanded method notes, and Python walkthrough are there if you want to go further. You can use all the saved examples without running a model yourself.
