A photograph records appearance. A depth map estimates where surfaces lie. The interesting question is how a learned model crosses that gap—and what evidence would make us trust its answer.

This tutorial follows monocular depth estimation from geometric ambiguity to modern foundation models, then tests three pretrained checkpoints on a small, reproducible set of images. Mirrors, glass, thin structures, and poor visibility make useful teaching cases because an attractive prediction can still describe the wrong surface.

The project began with early neural depth prediction and transformer models. Following the instructor’s request for recent research, its scope now includes adapting foundation models, robustness fine-tuning, any-view geometry, and model compression. The literature review and the local experiments answer different questions: a paper explains a method and its reported evidence; our implementation shows what selected checkpoints actually did on selected inputs.

What you should be able to explain

  • Why a single image cannot uniquely determine physical scale.
  • How relative depth, inverse depth, and metric depth differ.
  • What pretrained representations contribute, and what adaptation changes.
  • How an evaluation protocol can make a result look stronger than it is.
  • How to inspect a prediction, find a failure, and make a defensible claim.

Allow about 20–27 minutes: roughly 15–19 minutes of reading plus 5–8 minutes of exploration. This is a planning estimate, not a timed user study. If you know camera geometry, skim lesson 2; spend the saved time comparing a mirror, a glass object, and an ordinary indoor scene.

Prerequisites

Basic familiarity with pixels, neural networks, and arithmetic is enough to follow the main argument. The evaluation lesson includes a short NumPy example for readers who want the implementation details.

How to use the experiments

On the experiment page, select a scene, an input condition, and a model. Reveal the predicted map, change the overlay, and move two pixel probes. Then compare the model’s ordering with the dataset’s annotated pairs. The sensor-depth explorer uses a separate indoor dataset. A result panel names the quantity and protocol rather than treating every colored map as meters.

The public website uses saved outputs from real local inference. Selecting a model loads its saved prediction; it does not execute a neural network in your browser. The accompanying local Python project supports fresh inference, including uploaded photographs. This distinction makes the tutorial usable on ordinary devices without hiding where the evidence came from.
