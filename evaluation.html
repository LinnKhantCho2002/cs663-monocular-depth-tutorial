Choose the evaluation question before the score. DA-2K gives annotated near and far pairs, not dense meter-valued depth. Our ordering study uses fifteen images and thirty-five pairs, selected before inference. Each model processes the same original, mildly dimmed, strongly dimmed, and blurred inputs. These transformations are controlled postprocessing, not a complete physical camera simulation. NYU supplies indoor sensor references. For six examples, we fit scale and shift in inverse-depth space using the same ground-truth pixels that we then score. That is oracle shape alignment, not uncalibrated metric performance. The mask requires sensor support, valid depth, and a crop. We average error per image. Correlated pairs and transformed copies are not independent scenes. The downloadable records preserve the exact protocol, revisions, and per-case results.

An evaluation protocol determines the meaning of a result. “Low error” is incomplete until the target, mask, alignment, sample selection, and aggregation are specified.

Different references answer different questions

NYU Depth V2 supplies indoor RGB and Kinect depth, including raw projected measurements and filled depth maps [10]. Filled holes are useful for visualization but are not all independent sensor measurements. KITTI’s depth-prediction benchmark uses outdoor driving imagery and LiDAR-derived references [11]. Its coverage and scene distribution differ from indoor data. Hypersim provides rendered indoor imagery and geometry [12]; synthetic precision still leaves a real-image transfer question. KITTI and Hypersim are reviewed here, not evaluated locally.

DA-2K provides manually annotated near/far pairs in diverse images [13]. Such a pair answers whether one annotated point should be closer than another. It does not supply a dense meter-valued reference for the whole image.

Our fixed local protocol

  • Ordering: the first three lexicographically sorted annotated images in each of five DA-2K categories, selected before inference: 15 images and 35 pairs.
  • Input conditions: original RGB; mild dimming, round(255 × 0.25 × (RGB/255)1.6); strong dimming, round(255 × 0.05 × (RGB/255)3); and Gaussian blur with radius min(height,width)/80.
  • Inference: float32, one view, a 518-pixel short-edge target with native patch-divisible rounding. V2 and AC share the native V2 preprocessing; DA3 has its own native processor.
  • Indoor shape: six fixed zero-based NYU labeled-file records: 0, 289, 578, 867, 1156, 1448. These are illustrative records, not a verified official test split.
  • Timing: five warmed, synchronized repetitions on the first NYU image using an Apple M4 and Metal/MPS. Include preprocessing, forward prediction, upsampling, and CPU transfer; exclude model loading and plotting.

The dimming transformations change appearance while retaining pixel geometry. They do not recreate physical night imaging: sensor noise, exposure duration, motion, demosaicing, clipping, and dynamic range are not modeled. Blur is a controlled image operation, not a complete camera model.

Why alignment changes the claim

Our relative outputs have no meter scale. On each NYU image we fit a q + b ≈ 1/Z* by least squares using reference depth Z*. We then invert the fitted output to obtain an aligned depth. The fit and the score use the same valid pixels. This is an oracle evaluation of shape agreement after access to the answer; it is not deployable metric calibration.

The valid mask requires finite raw sensor and filled reference depths between 0.1 and 10 meters, intersected with rows 45:471 and columns 41:601 (Python’s end-exclusive slices). A non-positive fitted scale is rejected. Aligned inverse values are clipped to [0.1,10] before inversion, and the fraction clipped within the scored mask is recorded.

# Educational oracle alignment; q is relative inverse depth.
mask = valid_sensor_mask & crop & (gt > 0.1) & (gt < 10)
x = q[mask].astype("float64")
target = 1.0 / gt[mask]
A = np.column_stack([x, np.ones_like(x)])
a, b = np.linalg.lstsq(A, target, rcond=None)[0]
if a <= 0:
    raise ValueError("Reversed ordering")
aligned = 1.0 / np.clip(a * q + b, 0.1, 10.0)
abs_rel = np.mean(np.abs(aligned[mask] - gt[mask]) / gt[mask])

Absolute relative error averages |prediction − reference|/reference; smaller is better. RMSE is the square root of mean squared meter error and emphasizes large errors. δ₁ is the fraction with max(prediction/reference, reference/prediction) < 1.25; larger is better. Our table averages per-image AbsRel equally across six images instead of pooling every pixel.

Each condition column has the same 35 pairs. AC retains two more correct pairs than V2 under strong digital dimming and one more under blur. Their clean counts are identical. The NYU aligned mean differs by only about 0.00020 between these two checkpoints; this tiny sample does not justify declaring a general winner. DA3-Small has lower pair counts under these perturbations, but it also succeeds on the clean mirror pair that V2 and AC miss.

The pictures are correlated within a scene, the pairs are correlated within a picture, and the changed inputs reuse those same pictures. Treating 180 predictions or millions of pixels as independent test scenes would inflate the evidence. Training-data overlap has not been audited. Architecture and training both change between V2 and DA3, so this study cannot assign a difference to a specific component.

Rank stability is a separate measurement: Spearman correlation between clean and changed predictions at up to 30,000 sampled pixels. High stability means a model kept similar ordering. It can keep a mistake consistently, so stability is not depth accuracy.
